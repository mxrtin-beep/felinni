Import calendars

Pull in a calendar from Apple, Google, Outlook, or anywhere else - merges into every tab alongside events.json. Google/Outlook: their calendar settings have a "secret address in iCal format" / "publish this calendar" link you can paste below. Apple: an iCloud calendar's public sharing link works the same way, or upload the events.json from the exporter above. ICS-link calendars refresh automatically every 30 minutes while the server is running, plus "Refresh now"; uploaded files need a re-upload to update.
